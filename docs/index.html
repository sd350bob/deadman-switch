Deadman Switch

Reset timer

To reset the timer, go to the repo’s Actions tab, select Deadman Switch, click Run workflow, and enter ${RESET_PARAM} as p.

Request secret

To request the secret, go to the Actions tab, select Deadman Switch, click Run workflow, and enter ${REQUEST_SECRET_PARAM} as p and your email address as email.

If the timer is < 7 days, the workflow will print Time remaining in the logs. If ≥ 7 days and your email is approved, you’ll receive the secret by email.
